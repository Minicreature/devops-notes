# Kernel

## Key Concepts

| Concept | Meaning |
|---|---|
| Kernel | Core interface between Hardware & Processes |
| Monolithic | Entire OS runs in single memory space — fast |
| Modular | Kernel can load/unload modules at runtime without reboot |

## Kernel Responsibilities

| Area | What it does |
|---|---|
| Memory Management | Allocates/deallocates memory between processes |
| Process Management | Schedules CPU time, creates/kills processes |
| Device Drivers | Communicates with hardware on behalf of software |
| System Call & Security | Gateway between User Space & Kernel Space |

## Kernel Space vs User Space

| Space | What lives here |
|---|---|
| Kernel Space | Kernel, Device Drivers — direct hardware access |
| User Space | Applications/Programs — no direct hardware access |

## Commands & Variations

| Command | Use |
|---|---|
| `uname` | Print basic system info |
| `uname -r` | Print kernel version only |
| `dmesg` | Print kernel ring buffer (boot messages, hardware events) |
| `dmesg \| grep -i usb` | Filter dmesg for USB related messages |
| `udevadm info --query=path --name=/dev/sda5` | Query device info for a specific device |
| `udevadm monitor` | Live monitor kernel & udev events (plug/unplug devices) |
| `lspci` | List all PCI devices (graphics card, NIC, etc.) |
| `lsblk` | List all block devices (disks, partitions) |
| `lscpu` | Show CPU architecture details |
| `lsmem` | Show memory range info |
| `lsmem --summary` | Show summarized memory info |
| `free -m` | Show RAM usage in MB |
| `free -k` | Show RAM usage in KB |
| `free -g` | Show RAM usage in GB |
| `lshw` | List detailed hardware info (needs sudo for full output) |
| `sudo command` | Run any command as super-user (root privileges) |

## Device Detection Flow

| Step | Component | Space |
|---|---|---|
| Hardware plugged in | USB / Disk | Physical |
| Kernel detects & fires | uevent | Kernel Space |
| udev receives uevent | Device Manager | User Space |
| Device file created | /dev/sdb1 | User Space |
| Mounted & readable | /media/username/usb_name | User Space |

    One liner: USB → Kernel (uevent) → udev → /dev/sdb1 → /media/
