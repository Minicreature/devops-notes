# Linux Boot System

## Boot Sequence Overview

| Stage | Name | What Happens |
|---|---|---|
| 1 | BIOS POST | Power On Self-Test - checks hardware compatibility. Fails here = won't proceed |
| 2 | Boot Loader | GRUB2 loads from /boot — presents boot menu, loads kernel |
| 3 | Kernel Initialisation | Kernel decompresses from /boot, loads into memory, initialises hardware & memory management |
| 4 | INIT / Systemd | Kernel starts PID 1 (systemd) — mounts filesystems, starts services, brings system to usable state |

Key Point: INIT is the old name for PID 1. Modern Linux replaced it with systemd. Kernel directly starts systemd as PID 1.

## Commands & Variations

| Command | Use |
|---|---|
| `ls -l /sbin/init` | Shows what PID 1 actually is (symlink to systemd on modern Linux) |
| `runlevel` | Show current and previous runlevel |
| `systemctl get-default` | Show current default systemd target |
| `systemctl set-default multi-user.target` | Change default boot target |
| `ls -ltr /etc/systemd/system/default.target` | Show what default.target points to |
| `file <filename>` | Show file type of any file or directory |
| `cat /proc/mount` | Shows mounts with mount options - no space info, direct from kernel |
| `df -hP` | Shows mounts with disk usage/space info |

## Runlevels → Systemd Targets

| Runlevel | Systemd Target | Function |
|---|---|---|
| 0 | poweroff.target | Shutdown |
| 1 | rescue.target | Single user / recovery mode |
| 2 | multi-user.target | Multi-user, no networking (basic) |
| 3 | multi-user.target | Multi-user with networking, CLI only |
| 4 | multi-user.target | User-defined / unused by default |
| 5 | graphical.target | Multi-user + GUI |
| 6 | reboot.target | Reboot |

## Key Symlink

    /etc/systemd/system/default.target → /lib/systemd/system/graphical.target
