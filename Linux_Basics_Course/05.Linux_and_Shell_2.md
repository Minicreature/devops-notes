# Linux & Shell 2

## File Size Commands

| Command | Use |
|---|---|
| `du -sk filename` | Disk usage in kilobytes |
| `du -sh filename` | Disk usage in human-readable format (KB/MB/GB) |
| `ls -lh filename` | File size in long listing, human-readable |

## TAR Archiving

| Command | Use |
|---|---|
| `tar -cf archive.tar f1 f2 f3` | Create a tar archive (-c create, -f filename) |
| `tar -tf archive.tar` | List contents inside tar without extracting (-t view) |
| `tar -xf archive.tar` | Extract tar archive (-x extract) |
| `tar -zcf archive.tar.gz f1 f2 f3` | Create + compress with gzip (-z) — output must be .tar.gz |
| `tar -zxf archive.tar.gz` | Extract a gzip-compressed tar |
| `tar -jcf archive.tar.bz2 f1 f2` | Create + compress with bzip2 (-j) |
| `tar -jxf archive.tar.bz2` | Extract a bzip2-compressed tar |
| `tar -Jcf archive.tar.xz f1 f2` | Create + compress with xz (-J) |
| `tar -Jxf archive.tar.xz` | Extract an xz-compressed tar |
| `tar -xf archive.tar -C /path/to/dir` | Extract into a specific directory |

## TAR Naming

| Concept | Meaning |
|---|---|
| `tar -cf archive.tar` | No compression — .tar extension is correct here |
| `tar -zcf archive.tar.gz` | gzip compressed — extension must be .tar.gz, not .tar |
| `tar -jcf archive.tar.bz2` | bzip2 compressed — extension must be .tar.bz2 |
| Extension is not automatic | tar does not rename the file for you — wrong extension = confusion later |
| -z flag and -cf are separate | -c creates the archive, -z compresses it — output name is your responsibility |

## Standalone Compression Tools

| Command | Use |
|---|---|
| `gzip filename` | Compress file → produces filename.gz, original deleted |
| `gzip -k filename` | Produces filename.gz and keeps the original intact |
| `gunzip filename.gz` | Decompress .gz file |
| `bzip2 filename` | Compress file → produces filename.bz2, better compression than gzip |
| `bunzip2 filename.bz2` | Decompress .bz2 file |
| `xz filename` | Compress file → produces filename.xz, best compression ratio |
| `unxz filename.xz` | Decompress .xz file |
| `zcat filename.gz` | Read gzip file contents without extracting |
| `bzcat filename.bz2` | Read bzip2 file contents without extracting |
| `xzcat filename.xz` | Read xz file contents without extracting |

Key Concept: Compression tools delete the original by default. Use `gzip -k filename` to keep the original.

## Searching For Files

| Command | Use |
|---|---|
| `locate filename` | Fast file search using mlocate.db database |
| `updatedb` | Update the locate database manually (run as root) |
| `find /path -name filename` | Find file by exact name under given path |
| `find /path -name "*.txt"` | Find all files with .txt extension |
| `find /path -type d -name dirname` | Find only directories by name |
| `find /path -size +10M` | Find files larger than 10MB |

Key Concept: locate is fast but stale — reads from a database updated by cron. If file was just created, run updatedb first. find is slower but always real-time.

## GREP - Searching Inside Files

| Command | Use |
|---|---|
| `grep word filename` | Print lines containing the word (case sensitive) |
| `grep -i word filename` | Case insensitive search |
| `grep -r word /path` | Recursive search across all files in a directory |
| `grep -v word filename` | Invert — print lines that do NOT contain the word |
| `grep -w word filename` | Match whole word only (not partial matches) |
| `grep -A1 word filename` | Print matched line + 1 line After it |
| `grep -B1 word filename` | Print matched line + 1 line Before it |
| `grep -A2 -B2 word filename` | Print 2 lines above and below the matched line |
| `grep -n word filename` | Show line numbers with matches |
| `grep -c word filename` | Count how many lines match |

Key Concept: -A and -B stand for After and Before. -A2 -B2 gives full context around a match — very useful in log files.

## IO Redirection

| Stream | Number | Default Destination |
|---|---|---|
| stdin | 0 | Keyboard |
| stdout | 1 | Terminal screen |
| stderr | 2 | Terminal screen |

| Command | Use |
|---|---|
| `command > file.txt` | Redirect stdout to file (overwrites) |
| `command >> file.txt` | Redirect stdout to file (appends) |
| `command 2> file.txt` | Redirect stderr to file (overwrites) |
| `command 2>> file.txt` | Redirect stderr to file (appends) |
| `command 2> /dev/null` | Discard stderr entirely |
| `command > file.txt 2>&1` | Redirect both stdout and stderr to same file |
| `command &> file.txt` | Shorthand — redirect both stdout and stderr |

Key Concept: /dev/null is a black hole. Anything sent there is gone. Use `2> /dev/null` when you want output but not error noise.

## Pipes & TEE

| Command | Use |
|---|---|
| `command1 \| command2` | Pipe stdout of command1 as stdin of command2 |
| `echo $SHELL \| tee filename.txt` | Print to screen AND write to file (overwrites) |
| `echo $SHELL \| tee -a filename.txt` | Print to screen AND append to file |

Key Concept: tee does two things at once. Without it, > saves but doesn't print. tee lets you see output and save simultaneously — think of it as a T-junction in a pipe.
