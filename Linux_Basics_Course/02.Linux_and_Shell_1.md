# Linux & Shell 1

## Commands

| Command | Use |
|---|---|
| `echo $HOME` | Print home directory path of current user |
| `echo $SHELL` | Check current shell in use |
| `whatis command` | One-line description of a command |
| `man command` | Full manual for a command |
| `apropos keyword` | Search man pages by keyword when you know the task but not the exact command name |
| `command --help` | Quick usage summary |
| `chsh` | Change default shell (needs new terminal session to take effect) |
| `history` | View previously executed commands |
| `alias dt="date"` | Create a shortcut for a command |
| `env` | List all active environment variables |
| `which command` | Find where a command's binary lives in PATH |
| `more filename` | View file page by page |
| `less filename` | View file with better navigation |
| `pushd /path` | Go to directory while saving current location |
| `popd` | Return to previously saved location |
| `export VAR=value` | Create environment variable for current session |
| `export PATH=$PATH:/new/path` | Add new directory to PATH |
| `echo $PS1` | View current prompt configuration |
| `PS1="custom"` | Customise shell prompt |
| `sudo chsh -s /bin/sh user` | Change shell for a specific user (admin action) |
| `source ~/.profile` | Apply profile changes without logging out/rebooting |
| `echo 'export MY_VAR="value"' >> ~/.profile` | Permanently save environment variable |
| `echo 'alias ll="ls -l"' >> ~/.profile` | Permanently save an alias |
| `echo 'PS1="[\d]\u@\h:\w$ "' >> ~/.profile` | Permanently save custom prompt |

## Key Files

| File | Purpose |
|---|---|
| `~/.profile` | Permanent user-level env variables, aliases, prompt config |
| `~/.pam_environment` | Alternative file for persistent environment variables |

## Common Environment Variables

| Variable | Meaning |
|---|---|
| `$SHELL` | Current shell in use |
| `$HOME` | Current user's home directory |
| `$USER` | Logged-in username |
| `$PATH` | Directories bash searches for commands left to right |
| `$PWD` | Current working directory |
| `$PS1` | Controls how your prompt looks |

| Key | more | less |
|---|---|---|
| Space | Next screen | Next screen |
| Enter | Next line | - |
| Up/Down Arrow | - | Scroll line by line |
| b | Back one screen | Back one screen |
| / | Search | Search |
| q | Quit | Quit |

## PS1 Special Characters

| Character | Displays |
|---|---|
| `\u` | Username |
| `\h` | Hostname |
| `\w` | Full current working directory |
| `\W` | Current directory name only |
| `\d` | Date |
| `\t` | Time |

## Key Concepts

| Concept | Meaning |
|---|---|
| more vs less | less is better — supports up/down arrows. more is older, forward only |
| pushd/popd | Stack based navigation — save location, go somewhere, come back |
| Man page section numbers | e.g. date (1) — 1 = user commands, 8 = system admin commands |
| export vs no export | Without export, variable stays in current shell only — child processes can't see it |
| PATH | Bash searches these directories left to right to find a command — if not found, "command not found" error |
| Alias persistence | Aliases are session only unless saved to ~/.bashrc |
| Variable persistence | Add export lines to ~/.bashrc or ~/.profile to survive reboot |
| Trailing newline | echo adds a newline by default — -n suppresses it. Matters in scripts where clean output is needed |
