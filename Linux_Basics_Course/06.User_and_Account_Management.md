# User & Account Management

## Linux Security Overview

| Layer | Tool | Purpose |
|---|---|---|
| Access Control | User & Password | Authenticate users to the system |
| PAM | Pluggable Authentication Module | Authenticate users to programs & services |
| Network Security | iptables / Firewalld | Restrict or allow access to services |
| SSH Hardening | Secure Shell | Secure remote server access |
| SELinux | Security Policies | Isolate applications on the same system |

## Account Types

| Type | UID Range | Notes |
|---|---|---|
| Superuser (root) | 0 | Unrestricted access to everything |
| System Accounts | ≤ 100 or 500–1000 | Created during OS install, no /home/ directory |
| Service Accounts | varies | Created when services are installed, similar to system accounts |
| User Accounts | ≥ 1000 | Regular human users (Ubuntu starts at 1000) |

## Access Control Files

| File | Stores | Password Saved? |
|---|---|---|
| `/etc/passwd` | Username, UID, GID, Home Dir, Shell | No (x is placeholder) |
| `/etc/shadow` | Hashed passwords + aging info | Yes (hashed) |
| `/etc/group` | Group name, GID, Members | No |

## File Field Orders

    /etc/passwd  → USERNAME : PASSWORD(x) : UID : GID : GECOS : HOMEDIR : SHELL
    /etc/shadow  → USERNAME : HASHED_PASSWORD : LASTCHANGE : MINAGE : MAXAGE : WARN : INACTIVE : EXPDATE
    /etc/group   → GROUPNAME : PASSWORD(x) : GID : MEMBERS(comma-separated)

## Commands & Variations

| Command | Use |
|---|---|
| `id` | Show current user's UID, GID, groups |
| `id <username>` | Show specific user's UID, GID, groups |
| `who` | Show who is currently logged in |
| `last` | Show login history of users |
| `whoami` | Show current logged-in username |
| `cat /etc/passwd` | View all user accounts |
| `cat /etc/shadow` | View hashed passwords (root only) |
| `cat /etc/group` | View all groups |
| `sudo grep -i <username> /etc/passwd` | Find specific user entry |
| `grep -i ^root /etc/passwd` | Check root's shell (nologin check) |

## User Management Commands

| Command | Use |
|---|---|
| `useradd <username>` | Create a new user |
| `useradd -c "comment" <username>` | Add custom comment/description |
| `useradd -d /custom/path <username>` | Set custom home directory |
| `useradd -e 2025-12-31 <username>` | Set account expiry date |
| `useradd -g <GID> <username>` | Set primary group |
| `useradd -G grp1,grp2 <username>` | Add to multiple secondary groups |
| `useradd -s /bin/bash <username>` | Set login shell |
| `useradd -u <UID> <username>` | Set specific UID |
| `passwd <username>` | Set/change another user's password (root) |
| `passwd` | Change your own password |
| `userdel <username>` | Delete user (keeps home dir) |
| `userdel -r <username>` | Delete user AND home directory |
| `groupadd <groupname>` | Create a new group |
| `groupadd -g <GID> <groupname>` | Create group with specific GID |
| `groupdel <groupname>` | Delete a group |

## Switching Users & Sudo

| Command | Use | Needs Whose Password |
|---|---|---|
| `su -` | Switch to root | Root's password |
| `su <username>` | Switch to another user | That user's password |
| `su - <username>` | Switch with that user's full environment | That user's password |
| `su -c "<command>"` | Run single command as another user | That user's password |
| `sudo <command>` | Run command as root | Your OWN password |
| `sudo -i` | Open root shell via sudo | Your OWN password |

## Sudoers File

| Command | Use |
|---|---|
| `sudo visudo` | Safely edit sudoers file — validates syntax before saving |
| `sudo grep <username> /etc/sudoers` | Check if a user has sudo entry (read-only check) |

Path: `/etc/sudoers`

Note: Always edit using visudo — it validates syntax before saving. Direct editing can break sudo for everyone.

## Sudoers Syntax

    <user/group>  <host>=(<run-as-user>:<run-as-group>)  <command>

    bob ALL=(ALL:ALL) ALL                            -- Full sudo access
    sarah localhost=/usr/sbin/shutdown -r now        -- Only this one command
    %sudo ALL=(ALL:ALL) ALL                          -- All users in 'sudo' group

| Symbol | Meaning |
|---|---|
| `#` | Comment line |
| `%groupname` | Applies to a group |
| `ALL` (host) | Any machine |
| `ALL` (run-as) | Can run as any user |
| `ALL` (command) | Any command allowed |

## Key Concepts

| Concept | Meaning |
|---|---|
| Primary Group | Default group — GID matches UID if not specified at creation |
| Secondary Groups | Additional groups a user belongs to |
| nologin shell | /usr/sbin/nologin — prevents interactive login for that user |
| GECOS field | Comma-separated user info in /etc/passwd (full name, phone, etc.) |
| x in password field | Actual password is stored in /etc/shadow, not here |
