# Introduction to Shell

## Shell Basics

| Topic | Key Point |
|---|---|
| What is a Shell | Mediator between you and the OS. Commands execute instantly, output returns in the same window. |
| Home Directory | /home/username - your personal workspace. Represented by ~ (tilde) in the prompt. |
| pwd | Confirm which directory you're currently in. |

## Commands & Variations

| Command | Use |
|---|---|
| `uptime` | Shows how long system has been running + load average |
| `type command_name` | Check if a command is internal or external |

## Command Types

| Type | Meaning | Examples |
|---|---|---|
| Internal (Built-in) | Part of the shell itself | cd, pwd, echo, export, type |
| External | Separate binary on the system | mv, uptime, ls |

## Key Concepts

| Concept | Meaning |
|---|---|
| `~` in prompt | You are in your home directory |
| Arguments | Extra input that changes what a command acts on |
| Options/Flags | Modify how a command behaves (start with -) |
| Trailing newline | echo adds a newline by default after every output. -n suppresses it — matters in scripts where you need clean output without extra line breaks |
