# More Linux Commands

## Basic Commands

| Command | Use |
|---|---|
| `whoami` | Shows the current logged-in username |
| `id` | Shows detailed user information (UID, GID, groups) |
| `id username` | Check specific user's ID info |
| `su abcd` | Switch to user 'abcd' |
| `su -` | Switch to root |
| `su - abcd` | Switch with user's environment |
| `ssh abcd@1.1.1.1` | Access remote system as user 'abcd' |
| `ssh -p 2222 user@host` | Custom port |
| `ssh -i key.pem user@host` | Use specific key |
| `curl http://url/file.txt` | Print output to screen |
| `curl http://url/file.txt -O` | Download with original filename |
| `curl http://url/file.txt -o custom.txt` | Save with custom name |
| `wget http://url/file.txt` | Auto-save with original name |
| `wget http://url/file.txt -O custom.txt` | Save with custom name |
| `ls /etc/*release*` | List OS release info files |
| `cat /etc/*release*` | Display detailed OS release information |

## Important Directories

| Path | Purpose |
|---|---|
| `/root` | Home directory of the root user (admin/BOSS user) |
| `/` | Root directory (top level of entire filesystem) |
| `/etc/sudoers` | File containing users with sudo privileges |

## Key Concepts

| Concept | Meaning |
|---|---|
| Root user | Admin user (the BOSS) |
| sudo | Users in /etc/sudoers can execute commands with elevated privileges |
| visudo | Always use this to safely edit sudoers file |
