# Node.js & JavaScript

## Key Concepts

| Concept | Explanation |
|---|---|
| JavaScript | The programming language |
| Node.js | Server-side runtime for JavaScript (like JVM for Java) |
| V8 Engine | Google Chrome's JS engine — Node.js is built on top of it |
| Originally | JS was browser-only. Node.js brought it to servers. |

## Runtime Comparison

| Language | Runtime | Package Manager | Version Manager |
|---|---|---|---|
| Java | JVM | Maven / Ant | jenv |
| Python | PVM | pip | pyenv |
| JavaScript | Node.js | npm | nvm |

## NVM — Node Version Manager

| Command | Use |
|---|---|
| `nvm install 20` | Install Node version 20 |
| `nvm install 16` | Install Node version 16 |
| `nvm use 20` | Switch to Node version 20 |
| `nvm ls` | List all installed Node versions |
| `nvm alias default 20` | Set default Node version |

## Commands & Variations

| Command | Use |
|---|---|
| `node -v` | Check Node version |
| `wget <url> -O example-app.zip` | Download Node app zip |
| `unzip example-app.zip` | Unzip the file |
| `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh \| bash` | Install nvm |
| `. "$HOME/.nvm/nvm.sh"` | Load nvm without restarting shell |
| `nvm install --lts` | Install latest LTS version of Node |
| `sudo yum install nodejs -y` | Install Node via YUM (RHEL/CentOS) |
| `node filename.js` | Run a Node.js file |

## NPM — Node Package Manager

| Command | Use |
|---|---|
| `npm -v` | Check npm version |
| `npm init -y` | Create package.json for project |
| `npm install package_name` | Install package locally (project only) |
| `npm install -g package_name` | Install package globally (system-wide) |
| `npm uninstall package_name` | Remove a package |
| `npm list` | List installed packages |
| `npm outdated` | Check packages needing updates |
| `npm install` | Install all dependencies from package.json |
| `npm install --production` | Install only production dependencies |

## Local vs Global Install

| Type | Command | Stored In | Available |
|---|---|---|---|
| Local | `npm install express` | `node_modules/` | This project only |
| Global | `npm install -g nodemon` | System-wide path | Everywhere |

## package.json — Key Fields

| Field | Meaning |
|---|---|
| `name` | App name |
| `version` | App version |
| `main` | Entry point file (e.g. app.js) |
| `scripts.start` | Command run by npm start |
| `dependencies` | Packages needed in production |
| `devDependencies` | Packages needed only during development |

## package.json & package-lock.json

| File | Purpose |
|---|---|
| `package.json` | Says "I need express version 4 or above" |
| `package-lock.json` | Says "I installed express exactly 4.18.2" |

Always commit package-lock.json to Git!

## Built-in Modules (No install needed)

| Module | Use |
|---|---|
| `fs` | Read/write files |
| `http` | Create web servers |
| `os` | Get system info (hostname, CPU, memory) |
| `path` | Handle file paths |
| `events` | Event handling |
| `tls` | Implement TLS & SSL |
| `url` | Parse URL strings |

## External Modules (npm install required)

| Module | Use |
|---|---|
| `express` | Web framework |
| `react` | User interface |
| `debug` | Debug applications |
| `async` | Work with asynchronous JS |
| `lodash` | Work with arrays, objects, strings |

## Starting a Node App

| Command | Use |
|---|---|
| `node app.js` | Basic way to run app |
| `npm start` | Uses start script from package.json |
| `nodemon app.js` | Dev mode — auto restarts on file change |

## Key Locations

| Path | Purpose |
|---|---|
| `node_modules/` | All installed packages — never commit to Git |
| `package.json` | App's dependency manifest |
| `package-lock.json` | Exact versions locked — always commit to Git |
| `/project/node_modules/pkg/package.json` | Package metadata |
