# IP & Ports

## Key Concepts

| Concept | Meaning |
|---|---|
| IP Address | Every device on a network gets an IP address — like a home address, packets need to know where to go |
| `127.0.0.1` | Loopback — your device talking to itself, never leaves your machine |
| `0.0.0.0` | Listen on ALL available interfaces — any IP this machine has |
| Multiple IPs | Connected to WiFi + Ethernet at same time? → Two different IPs |
| Port | Gets you to the right application on that machine |
| Total Ports | 65535 ports total |
| Reserved Ports | Ports 1–1023 are reserved/well-known |
| App Ports | Your apps typically run on 1024+ |
| Total Ports | 65535 ports total — Ports 1–1023 are reserved/well-known. Your apps typically run on 1024+ |

## Well Known Ports

| Port | Use |
|---|---|
| `22` | SSH |
| `80` | HTTP |
| `443` | HTTPS |
| `5000` | Flask app |
| `6379` | Redis |
| `3306` | MySQL |
| `27017` | MongoDB |
| `8080` | Tomcat |
| `3000` | ExpressJS |

## The Combo That Matters in DevOps

    IP:Port → 192.168.1.10:5000

IP gets you to the machine. Port gets you to the right application on that machine. In Docker/K8s you will see this everywhere.
