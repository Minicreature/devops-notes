# Package Managers

## Package Manager Hierarchy

| Layer | Debian / Ubuntu | RHEL / CentOS / Fedora |
|---|---|---|
| Base Package Manager | `dpkg` | `rpm` |
| Frontend (Simple) | `apt` | `yum` |
| Frontend (Feature Rich / Modern) | `apt-get` | `dnf` |

Key Concept: Frontend tools (apt, yum, dnf) sit on top of the base managers and handle dependency resolution automatically. Base managers (dpkg, rpm) do not resolve dependencies on their own.

## DPKG (Ubuntu / Debian)

| Command | Use |
|---|---|
| `dpkg -i package_name.deb` | Install a package |
| `dpkg -r package_name` | Remove package, keeps config files |
| `dpkg -P package_name` | Purge package and config files |
| `dpkg -l package_name` | Query if package is installed |
| `dpkg -l` | List all installed packages |
| `dpkg --get-selections` | Show all installed packages with status |
| `dpkg -s package_name` | Show package details/status |
| `dpkg -L package_name` | List all files installed by a package |

Package format: `.deb`

## APT (Ubuntu / Debian)

| Command | Use |
|---|---|
| `apt update` | Refresh repo index (always run before install) |
| `apt install package_name` | Install package with dependencies |
| `apt remove package_name` | Remove package, keeps config files |
| `apt purge package_name` | Remove package and config files |
| `apt autoremove` | Clean up unused dependencies |
| `apt upgrade` | Upgrade all installed packages |
| `apt list --installed` | List all installed packages |
| `apt show package_name` | Show package details |
| `apt search package_name` | Search available packages |
| `apt list -a package_name` | Show all available versions of a package |
| `apt install package_name=version` | Install a specific version |
| `apt-cache depends package_name` | Show dependencies of a package |
| `apt-file search scp` | Debian/Ubuntu equivalent — find which package provides a file |
| `apt edit-sources` | Edit repo sources — opens /etc/apt/sources.list in your chosen text editor |

Repo config location: `/etc/apt/sources.list` and `/etc/apt/sources.list.d/`

## RPM (RHEL / CentOS / Fedora)

| Command | Use |
|---|---|
| `rpm -i package_name.rpm` | Install a package |
| `rpm -ivh package_name.rpm` | Install with verbose output and progress bar |
| `rpm -U package_name.rpm` | Upgrade a package |
| `rpm -e package_name` | Uninstall a package |
| `rpm -q package_name` | Query if package is installed |
| `rpm -qa` | List all installed packages |
| `rpm -qi package_name` | Show package details/info |
| `rpm -ql package_name` | List all files installed by a package |
| `rpm -qf /path/to/file` | Find which package owns a file |
| `rpm -qd package_name` | List documentation files of a package |
| `rpm -V package_name` | Verify integrity of an installed package |
| `rpm -Vf package_name` | Verify integrity of an installed package |

Package format: `.rpm`
Key Path: `/var/lib/rpm` — all info about all rpm packages installed

## YUM (RHEL / CentOS / Fedora)

| Command | Use |
|---|---|
| `yum install package_name` | Install package with all dependencies |
| `yum remove package_name` | Remove installed package |
| `yum list package_name` | Check if package is available or installed |
| `yum repolist` | Show all available repos |
| `yum --showduplicates list package_name` | Show all versions of a package |
| `yum install package_name-2.4.2.0` | Install a specific version |
| `yum install http://.../path.rpm` | Add a new repo and install from URL |
| `yum provides package` | Shows which package can help here |
| `yum upgrade` | Upgrades it to the latest version |
| `yum update package_name` | Shows all updates for specific package |
| `yum update` | Shows updates for all the installed packages |
| `yum provides scp` | Find which package provides a specific binary or file |

Repo config location: `/etc/yum.repos.d`

## Key Concepts

| Tool | Works On | Won't Work On |
|---|---|---|
| RPM / YUM / DNF | RHEL, CentOS, Fedora | Ubuntu, Debian |
| DPKG / APT | Ubuntu, Debian | RHEL, CentOS, Fedora |

They are not interchangeable. `.rpm` files and `.deb` files are built differently and can't be read by the other's tools.
