# Vi Editor

## Modes

| Mode | How to Enter |
|---|---|
| Command Mode | Default mode (press ESC to return here) |
| Insert Mode | Press `i` to enter (for typing/editing) |
| Last Line Mode | Press `:` from Command Mode (for save/quit/search) |

## Navigation

| Command | Use |
|---|---|
| `h j k l` | Left, Down, Up, Right (or use arrow keys) |
| `gg` | Jump to first line of file |
| `G` | Jump to last line of file |
| `0` | Jump to start of current line |
| `$` | Jump to end of current line |
| `Ctrl+u` | Scroll up half page |
| `Ctrl+d` | Scroll down half page |

## Editing - Delete

| Command | Use |
|---|---|
| `x` | Delete single character |
| `dd` | Delete entire line |
| `5dd` | Delete 5 lines (or any number) |
| `dG` | Delete from current line to end of file |

## Editing - Copy & Paste

| Command | Use |
|---|---|
| `yy` | Copy (yank) current line |
| `5yy` | Copy 5 lines |
| `p` | Paste below current line |

## Editing - Insert

| Command | Use |
|---|---|
| `i` | Insert at current position |
| `o` | Open new line below + enter insert mode |
| `O` | Open new line above + enter insert mode |
| `ESC` | Exit insert mode (back to Command Mode) |

## Undo & Redo

| Command | Use |
|---|---|
| `u` | Undo last change |
| `Ctrl+r` | Redo |

## Search

| Command | Use |
|---|---|
| `/word` | Find "word" in file |
| `n` | Jump to next match |
| `N` | Jump to previous match |

## Save & Quit (Last Line Mode)

| Command | Use |
|---|---|
| `:w` | Save file |
| `:w filename` | Save as new filename |
| `:q` | Quit (only works if no changes) |
| `:q!` | Quit without saving (force quit) |
| `:wq` | Save and quit |
| `:wq!` | Save and quit (force) |

## Quick Tips

| Tip | Detail |
|---|---|
| ESC first | Always press ESC if unsure which mode you're in |
| Repetition | Use number + command: `5dd`, `10yy`, `3x` |
| Navigation | `G` and `gg` save tons of scrolling time |
| New lines | Use `o` instead of `i` + arrow keys when adding new lines |
