# SSL & TLS Basics

## Core Concepts

| Concept | Meaning |
|---|---|
| SSL | Secure Sockets Layer — older protocol (mostly deprecated) |
| TLS | Transport Layer Security — modern replacement for SSL |
| Confidentiality | Data only accessible by Client & Server → Encryption |
| Integrity | Data not modified in transit → Hashing |
| Authentication | Verifying identity of Client/Server → PKI |

## Roles in TLS

| Role | Who | Always Authenticated? |
|---|---|---|
| Client | Browser, phone, app, IoT device | No (optional, rare) |
| Server | Apache, IIS, Nginx, Load Balancer, SSL Accelerator | Yes, always |

## Certificate Authority (CA)

| Point | Detail |
|---|---|
| What it does | Issues certificates, acts as Trust Anchor |
| Trust chain | If we trust the CA → we trust what CA trusts |
| Top 5 CAs | IdenTrust (Let's Encrypt), DigiCert, Sectigo (Comodo), GoDaddy, GlobalSign |
| Coverage | These 5 secure ~98% of the Internet |

## Encryption Types

| Type | Keys Used | Speed | Security | Text Size |
|---|---|---|---|---|
| Symmetric | Same key for encrypt & decrypt | Fastest, low CPU | Less secure (key must be shared) | Plain = Cipher |
| Asymmetric | Different keys (Public + Private) | Slower, high CPU | More secure | Cipher expands |
| Hybrid | Asymmetric to share key → then Symmetric for data | Best of both | Best of both | — |

## Private vs Public Key Usage

| Key | Used For | Provides |
|---|---|---|
| Private Key | Asymmetric Decryption | Confidentiality |
| Private Key | Asymmetric Encryption | Signatures → Integrity & Authentication |
| Public Key | Asymmetric Encryption | Confidentiality |
| Public Key | Asymmetric Decryption | Signatures → Integrity & Authentication |

## Signatures

| Concept | Detail |
|---|---|
| What it is | Sender's Private Key encrypts the Hash of data |
| What it provides | Integrity + Authentication |

## SSH Key Commands

| Command | Use |
|---|---|
| `ssh-keygen` | Generate SSH key pair (default) |
| `ssh-keygen -t rsa` | Generate RSA key pair specifically |
| `cat ~/.ssh/authorized_keys` | View authorized public keys on server |
| `ssh -i private_key user@server` | Connect using specific private key |
| `ssh-copy-id -i .ssh/mykey.pub user@server` | Copy public key to server (easy method) |
| `ssh -i .ssh/mykey user@server 'echo Success'` | Test key-based login |

## OpenSSL Commands

| Command | Use |
|---|---|
| `yum install -y openssl` | Install OpenSSL |
| `openssl genrsa -out private_key.pem 2048` | Generate 2048-bit RSA private key |
| `openssl rsa -in private_key.pem -pubout -out public_key.pem` | Extract public key from private key |
| `openssl req -new -key my-bank.key -out my-bank.csr -subj "/C=US/..."` | Generate CSR with subject details inline |
| `openssl req -new -newkey rsa:2048 -nodes -keyout app01.key -out app01.csr` | Generate key + CSR together (interactive) |
| `openssl req -noout -text -in app01.csr` | Read/inspect a CSR |
| `openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout app01.key -out app01.crt` | Generate self-signed certificate (365 days) |
| `openssl x509 -in app01.crt -text -noout` | Read/inspect a certificate |

## Key Files & Locations

| Path | Purpose |
|---|---|
| `~/.ssh/authorized_keys` | Stores allowed public keys on server |
| `/etc/httpd/csr/` | Store CSR files (Apache convention) |
| `/etc/httpd/certs/` | Store certificate files (Apache convention) |
| `/etc/httpd/conf.d/ssl.conf` | Apache SSL configuration file |

## File Types Cheatsheet

| Extension | What it is |
|---|---|
| `.key` | Private key file |
| `.pem` | Public key or certificate (PEM format) |
| `.csr` | Certificate Signing Request |
| `.crt` | Signed Certificate |
