# Apache Web Server

## Commands & Variations

| Command | Use |
|---|---|
| `sudo apt install apache2 -y` | Install Apache on Ubuntu/Debian |
| `sudo systemctl start apache2` | Start Apache service |
| `sudo systemctl stop apache2` | Stop Apache service |
| `sudo systemctl restart apache2` | Restart Apache (apply config changes) |
| `sudo systemctl status apache2` | Check if Apache is running |
| `sudo systemctl enable apache2` | Auto-start Apache on boot |
| `sudo systemctl disable apache2` | Don't auto-start on boot |
| `sudo apache2ctl configtest` | Test config syntax before restarting (USE THIS ALWAYS) |
| `sudo a2enmod module_name` | Enable an Apache module |
| `sudo a2dismod module_name` | Disable an Apache module |
| `sudo a2ensite site_name` | Enable a virtual host site |
| `sudo a2dissite site_name` | Disable a virtual host site |

## Troubleshooting Commands

| Command | Use |
|---|---|
| `sudo ss -tlnp \| grep :80` | Check what process is using port 80 |
| `sudo lsof -i :80` | See detailed process info using port 80 |
| `sudo tail -f /var/log/apache2/access.log` | Watch live access logs |
| `sudo tail -f /var/log/apache2/error.log` | Watch live error logs |
| `curl http://localhost` | Test if Apache is serving locally |
| `curl http://localhost:9090` | Test Apache on a custom port |

## Key Files & Locations

| File/Path | Purpose |
|---|---|
| `/etc/apache2/apache2.conf` | Main Apache config file |
| `/etc/apache2/ports.conf` | Where Listen port is configured |
| `/etc/apache2/sites-available/` | Virtual host config files live here |
| `/etc/apache2/sites-enabled/` | Active virtual host symlinks |
| `/var/www/html/` | Default document root (static files go here) |
| `/var/log/apache2/access.log` | User access history |
| `/var/log/apache2/error.log` | Error details |

## Important Directives

| Directive | Use |
|---|---|
| `Listen 80` | Port Apache listens on |
| `DocumentRoot /var/www/html` | Where static content is served from |
| `ServerName www.example.com:80` | DNS name of the host |

## Virtual Host Example

    <VirtualHost *:80>
        ServerName www.first.com
        DocumentRoot /var/www/first
    </VirtualHost>

    <VirtualHost *:80>
        ServerName www.second.com
        DocumentRoot /var/www/second
    </VirtualHost>

## RHEL vs Ubuntu Differences

| Item | Ubuntu/Debian | RHEL/CentOS |
|---|---|---|
| Package name | `apache2` | `httpd` |
| Install command | `apt install apache2` | `yum install httpd` |
| Start command | `systemctl start apache2` | `systemctl start httpd` |
| Main config | `/etc/apache2/apache2.conf` | `/etc/httpd/conf/httpd.conf` |
| Logs location | `/var/log/apache2/` | `/var/log/httpd/` |
| Module enable/disable | `a2enmod / a2dismod` | Edit config file manually |

## Key Learnings

| Concept | Meaning |
|---|---|
| Port conflict | Only one process can own a port at a time — use ss or lsof to find who owns it |
| autoindex module | Shows directory listing when index.html is missing — disable in production (security risk) |
| Config syntax error | Apache refuses to start if config has invalid directives — always run configtest first |
| ports.conf change | Changing Listen port requires restart to take effect |
| `apache2ctl configtest` | Always run this before restarting Apache in production to avoid downtime |
