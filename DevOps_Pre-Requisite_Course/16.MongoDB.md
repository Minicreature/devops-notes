# MongoDB

## Concepts

| Concept | SQL (Relational) | NoSQL (Non-Relational) |
|---|---|---|
| Structure | Tables (rows & columns) | Documents (JSON format) |
| Group of data | Table | Collection |
| Query example | `SELECT * FROM table WHERE arg` | `db.collection.find({arg})` |
| Examples | MySQL, PostgreSQL, MS SQL Server | MongoDB, DynamoDB, Cassandra |

## Installation & Service

| Command | Use |
|---|---|
| Add repo file to `/etc/yum.repos.d/` | Add MongoDB community repo before install |
| `yum install mongodb-org` | Install MongoDB |
| `systemctl start mongod` | Start MongoDB service |
| `systemctl status mongod` | Check service status |

## Key Files & Info

| Item | Detail |
|---|---|
| Repo location | `/etc/yum.repos.d/<community-version-file>` |
| Config file | `/etc/mongod.conf` |
| Log file | `/var/log/mongodb/mongod.log` |
| Default port | `27017` |

## Mongo Shell Commands

| Command | Use |
|---|---|
| `mongo` | Open MongoDB shell |
| `show dbs` | List all databases |
| `use db_name` | Switch to / create a database |
| `db` | Show currently selected database |
| `db.createCollection("collection_name")` | Create a collection |
| `show collections` | List all collections in current DB |
| `db.collection_name.insert({ "field": "value" })` | Insert a document |
| `db.collection_name.find()` | Fetch all documents |
| `db.collection_name.find({"field": "value"})` | Fetch with filter |
