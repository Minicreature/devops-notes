# MySQL

## Concepts

| Concept | SQL (Relational) | NoSQL (Non-Relational) |
|---|---|---|
| Structure | Tables (rows & columns) | Documents (JSON format) |
| Group of data | Table | Collection |
| Query example | `SELECT * FROM table WHERE arg` | `db.collection.find({arg})` |
| Examples | MySQL, PostgreSQL, MS SQL Server | MongoDB, DynamoDB, Cassandra |

## MySQL Installation & Service

| Command | Use |
|---|---|
| `wget <link>` | Download MySQL package |
| `rpm -ivh file_name` | Install RPM package |
| `yum install mysql-server` | Install MySQL server |
| `yum install mysql-community-server` | Install MySQL community edition |
| `service mysqld start` | Start MySQL service |
| `service mysqld status` | Check MySQL service status |
| `grep 'temporary password' /var/log/mysqld.log` | Get auto-generated root password |

## Key Paths

| Path | Purpose |
|---|---|
| `/var/log/mysqld.log` | MySQL log file (temp password lives here) |
| `/var/lib/mysql` | MySQL data directory on Linux |

## Login & User Management

| Command | Use |
|---|---|
| `mysql -u root -p` | Login as root user |
| `ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password';` | Change root password |
| `CREATE USER 'user'@'localhost' IDENTIFIED BY 'pass';` | Create user for localhost only |
| `CREATE USER 'user'@'%' IDENTIFIED BY 'pass';` | Create user accessible from anywhere |

## Database & Table Operations

| Command | Use |
|---|---|
| `SHOW DATABASES;` | List all databases |
| `CREATE DATABASE db_name;` | Create a new database |
| `USE db_name;` | Switch to a database |
| `SHOW TABLES;` | List all tables in current DB |
| `CREATE TABLE table_name (col1 datatype, col2 datatype);` | Create a table |
| `INSERT INTO table_name VALUES ('val1', 'val2');` | Insert a row |
| `SELECT * FROM table_name;` | Read all rows from a table |

## Privileges

| Command | Use |
|---|---|
| `GRANT ALL PRIVILEGES ON *.* TO 'user'@'%';` | Full access on all DBs |
| `GRANT SELECT, INSERT ON db_name.* TO 'user'@'%';` | Specific access on one DB |
| `GRANT SELECT ON db_name.table TO 'user'@'host';` | Access on specific table |
| `SHOW GRANTS FOR 'user'@'host';` | View user's permissions |
| `FLUSH PRIVILEGES;` | Apply privilege changes |

## Privilege Types

| Privilege | Meaning |
|---|---|
| `ALL PRIVILEGES` | Full access |
| `CREATE` | Create databases/tables |
| `DROP` | Delete databases/tables |
| `INSERT` | Add rows to table |
| `SELECT` | Read/query tables |
| `UPDATE` | Modify rows in table |
| `DELETE` | Remove rows from table |
