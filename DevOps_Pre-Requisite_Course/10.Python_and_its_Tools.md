# Python & it's tools

## Commands & Variations

| Command | Use |
|---|---|
| `python3 -V` | Check Python 3 version |
| `python2 -V` | Check Python 2 version |
| `python3 filename.py` | Execute a Python file with v3 |
| `python2 filename.py` | Execute a Python file with v2 |
| `python3 -c "code here"` | Run Python code directly in terminal |
| `pip3 -V` | Check pip3 version |
| `pip2 -V` | Check pip2 version |
| `pip3 install package_name` | Install a package |
| `pip3 install -r requirements.txt` | Install all packages from file |
| `pip3 install package_name --upgrade` | Upgrade a package |
| `pip3 uninstall package_name -y` | Uninstall a package |
| `pip3 show package_name` | Show package details |
| `pip3 list` | List all installed packages |
| `pip3 freeze > requirements.txt` | Capture installed packages to file |

## Virtual Environment

| Command | Use |
|---|---|
| `sudo apt install python3.12-venv` | Install venv support on Ubuntu |
| `python3 -m venv venv` | Create virtual environment (folder named venv) |
| `source venv/bin/activate` | Activate virtual environment |
| `deactivate` | Exit virtual environment |

## Key Concepts

| Concept | Meaning |
|---|---|
| python2 vs python3 | Not compatible with each other |
| pip2 vs pip3 | Separate package managers for each version |
| venv | Isolated environment per project |
| requirements.txt | Declares all dependencies explicitly |
| `.whl` | Wheel format - modern package format |
| `.egg` | Old format via easy_install - rarely used now |
