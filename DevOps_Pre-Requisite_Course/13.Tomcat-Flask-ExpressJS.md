# Tomcat / Flask / ExpressJS

## Apache Tomcat (Java)

| Command | Use |
|---|---|
| `sudo apt install default-jdk -y` | Install Java on Ubuntu |
| `java -version` | Check Java version |
| `wget <tomcat_url>` | Download Tomcat |
| `tar xvf filename.tar.gz` | Extract Tomcat |
| `./apache-tomcat-x.x.x/bin/startup.sh` | Start Tomcat |
| `./apache-tomcat-x.x.x/bin/shutdown.sh` | Stop Tomcat |
| `curl http://localhost:8080` | Test Tomcat |
| `jar -cvf app.war *` | Package app into WAR file |

## Tomcat Folder Structure

| Folder/File | Purpose |
|---|---|
| `bin/` | Scripts — .sh for Linux, .bat for Windows |
| `bin/startup.*` | Start Tomcat server |
| `bin/shutdown.*` | Stop Tomcat server |
| `conf/` | Configuration files |
| `conf/server.xml` | Connectors & port config |
| `conf/web.xml` | Deploy & configure specs |
| `logs/` | Tomcat log files |
| `logs/catalina.out` | WAR extraction & deploy logs |
| `webapps/` | Hosted web applications live here |

## Tomcat Key Concepts

| Concept | Meaning |
|---|---|
| Apache Tomcat | Web server for hosting Java based web apps |
| WAR file | Web Application Archive — packaged Java app deployed into webapps/ |
| Port 8080 | Tomcat's default port — can be changed in conf/server.xml |
| catalina.out | Main log file — first place to check when Tomcat has issues |
| `.sh vs .bat` | .sh scripts for Linux, .bat scripts for Windows |

## Flask (Python)

| Command | Use |
|---|---|
| `sudo apt install python3.12-venv -y` | Install venv support on Ubuntu 24.04 |
| `python3 -m venv venv` | Create virtual environment |
| `source venv/bin/activate` | Activate virtual environment |
| `deactivate` | Exit virtual environment |
| `pip3 install flask` | Install Flask (inside venv only on Ubuntu 24.04) |
| `pip3 show flask` | Verify Flask installation |
| `python3 app.py` | Run Flask app |
| `pip3 install gunicorn` | Install gunicorn |
| `gunicorn file_name:flask_app_component -w 2` | Deploy two workers of mentioned component in file |
| `curl http://localhost:5000` | Test Flask app |

## Flask app.py Structure

    from flask import Flask
    app = Flask(__name__)

    @app.route('/')
    def home():
        return 'Hello from Flask!'

    if __name__ == '__main__':
        app.run(debug=True)

## Flask Key Concepts

| Concept | Meaning |
|---|---|
| Flask | Python web framework — lightweight, needs app.run() to start |
| Gunicorn | Production server for Flask — runs multiple workers |
| `if __name__ == '__main__'` | Only starts Flask if file is run directly, not when imported |
| venv | Required on Ubuntu 24.04 before pip install — system Python is protected |

## ExpressJS (NodeJS)

| Command | Use |
|---|---|
| `sudo apt install nodejs npm -y` | Install NodeJS and npm |
| `npm init -y` | Initialize a Node project |
| `npm install express` | Install Express framework |
| `node index.js` | Run Express app |
| `sudo npm install pm2 -g` | Install pm2 globally |
| `pm2 start file_name` | Start app with pm2 |
| `pm2 start file_name -i 4` | Start app with 4 workers |
| `pm2 stop file_name` | Stop the app |
| `pm2 delete file_name` | Remove from pm2 list |
| `curl http://localhost:3000` | Test Express app |

## ExpressJS index.js Structure

    const express = require('express')
    const app = express()
    app.get('/', (req, res) => res.send('Hello from Express!'))
    app.listen(3000, () => console.log('Running on port 3000'))

## ExpressJS Key Concepts

| Concept | Meaning |
|---|---|
| Express JS | NodeJS web framework |
| pm2 | Process manager for NodeJS — keeps app alive, supports multiple workers |
| `-i 4` | Runs 4 worker instances of the app |
