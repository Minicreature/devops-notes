# Linux Basics

## Navigation & Directory Operations

| Command | Use |
|---|---|
| `pwd` | Print current working directory |
| `cd <directory>` | Change directory |
| `cd ..` | Go up one directory level |
| `cd ~` | Go to home directory |
| `mkdir <dirname>` | Create a directory |
| `mkdir -p path/to/dir` | Create nested directories (parents too) |

## File Operations

| Command | Use |
|---|---|
| `touch <filename>` | Create empty file or update timestamp |
| `touch file1 file2 file3` | Create multiple files at once |
| `touch "my file.txt"` | Create file with spaces (use quotes) |
| `touch my\ file.txt` | Create file with spaces (use backslash) |
| `cat <filename>` | Display file contents |
| `cat > file.txt` | Create file and write content (Ctrl+D to save) |
| `cat >> file.txt` | Append content to existing file |
| `echo "text" > file.txt` | Write text to file (overwrites) |
| `echo "text" >> file.txt` | Append text to file |
| `cp source dest` | Copy file |
| `cp -r source dest` | Copy directory recursively |
| `mv source dest` | Move or rename file/directory |
| `rm <filename>` | Remove file |
| `rm -r <dirname>` | Remove directory recursively |

## Listing & Viewing

| Command | Use |
|---|---|
| `ls` | List files and directories |
| `ls -l` | Long format (detailed view) |
| `ls -a` | Show all files (including hidden) |
| `ls -h` | Human-readable file sizes |
| `ls -t` | Sort by modification time (newest first) |
| `ls -r` | Reverse order |
| `ls -lah` | Combine: long, all, human-readable |
| `ls -laht` | Above + sorted by time |
| `ls -lahrt` | Above + reversed (oldest first) |
| `ls -lahS` | Long, all, human, sorted by size |
| `tree` | Show directory structure as tree |

## Special Symbols & Operators

| Symbol | Use |
|---|---|
| `~` | Home directory shortcut |
| `.` | Current directory |
| `..` | Parent directory |
| `\|` | Pipe (send output to next command) |
| `&&` | AND operator (run next if first succeeds) |
| `;` | Run commands sequentially |
| `>` | Redirect output (overwrite) |
| `>>` | Redirect output (append) |
| `\` | Escape special characters |

## Key Learnings

| Concept | Meaning |
|---|---|
| Spaces in filenames | Use quotes or backslash to escape |
| Permission denied | Use ~ (home) instead of /tmp for practice |
| Pipe \| vs AND && | \| passes output; && runs if success |
| Deleting current directory | Possible but leaves shell "orphaned" |
| `mkdir -p` | No error if directory exists |
