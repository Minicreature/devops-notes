# Java & Build Tools

## Java Installation

| Command | Use |
|---|---|
| `sudo apt install default-jdk -y` | Download & install the latest stable version of JDK |
| `sudo curl https://download.java.net/java/GA/jdk20/.../openjdk-20_linux-x64_bin.tar.gz --output /opt/openjdk-20_linux-x64_bin.tar.gz` | Download OpenJDK 20 to /opt/ |
| `sudo tar -xf /opt/openjdk-20_linux-x64_bin.tar.gz -C /opt/` | Extract the archive to /opt/ |
| `/opt/jdk-20/bin/java -version` | Check Java version using full path |
| `export PATH=$PATH:/opt/jdk-20/bin` | Add Java to PATH permanently |

## Building Java App

| Command | Use |
|---|---|
| `javac MyClass.java` | Compile .java file → creates MyClass.class |
| `java MyClass` | Run the app by calling the class name |
| `java -jar MyApp.jar` | Run a packaged JAR application |
| `java -cp /path/.jar com.mycompany.app.App` | Run App class from a Maven-built JAR |
| `javadoc -d doc MyClass.java` | Generate HTML documentation from source code |

## ANT

| Command | Use |
|---|---|
| `ant` | Run all stages in build.xml |
| `ant phase_name` | Run only specified phase |
| `ant phase1 phase2` | Run specific phases e.g. ant package jar |

## Maven

| Command | Use |
|---|---|
| `mvn compile` | Run validate → compile |
| `mvn test` | Run validate → compile → test |
| `mvn package` | Run validate → compile → test → package |
| `mvn clean package` | Wipe previous build then full package — standard pipeline command |
| `mvn install` | Run up to install — copies JAR to ~/.m2 |
| `mvn deploy` | Full lifecycle — uploads to remote repo |

## ANT vs Maven — Default Stages

| Tool | Default Stages | Order |
|---|---|---|
| ANT | compile, test, package, jar | Only runs what YOU mention - no auto sequence |
| Maven | validate → compile → test → package → verify → install → deploy | Always runs everything up to mentioned phase |

## File Naming Convention

| Tool | Convention | Example |
|---|---|---|
| Maven JAR | artifactId-version.jar | my-app-1.0-SNAPSHOT.jar |
| Maven WAR | artifactId-version.war | shopping-cart-2.3.1.war |
| ANT | Whatever you define in build.xml | No fixed convention |

## Key Locations

| Path | Purpose |
|---|---|
| `~/.m2/repository` | Local Maven cache — dependencies & plugins stored here |
| `~/.m2/settings.xml` | Personal Maven config — repos, credentials |
| `target/` | All build output — JAR, WAR, .class files |
| `target/surefire-reports/` | Test results — check here when tests fail |
| `/META-INF/MANIFEST.MF` | Package metadata — entry point defined here |
