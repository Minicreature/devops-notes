# Services

## Commands & Variations

| Command | Use |
|---|---|
| `systemctl start service_name` | Start the service |
| `systemctl stop service_name` | Stop the service |
| `systemctl restart service_name` | Stop + Start again |
| `systemctl reload service_name` | Reload config without stopping |
| `systemctl status service_name` | Check if service is running |
| `systemctl enable service_name` | Auto-start on boot |
| `systemctl disable service_name` | Don't auto-start on boot |
| `systemctl is-enabled service_name` | Check if enabled on boot |
| `systemctl daemon-reload` | Reload systemd after file change |

## Old Style (Still Works)

| Command | Use |
|---|---|
| `service service_name start` | Start the service |
| `service service_name stop` | Stop the service |
| `service service_name status` | Check service status |

## Key Files & Locations

| Path | Purpose |
|---|---|
| `/etc/systemd/system/your_app.service` | Service file location |

## Service File Structure

    [Unit]
    Description=My python web app application

    [Service]
    ExecStart=/usr/bin/python3 /opt/code/my_app.py
    ExecStartPre=/opt/code/configure_db.sh
    ExecStartPost=/opt/code/email_start.sh
    Restart=always

    [Install]
    WantedBy=multi-user.target
