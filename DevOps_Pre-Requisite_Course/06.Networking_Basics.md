# Networking Basics

## Commands & Variations

| Command | Use |
|---|---|
| `ip link` | List/modify interfaces on host |
| `ip link set dev eth0 up` | Set interface state on host |
| `ip addr` | See IP addresses assigned to interfaces |
| `ip addr add 1.1.1.1/24 dev eth0` | Add IP to an interface |
| `ip route` | Check routing table |
| `ip route add 192.168.2.0/24 via 192.168.1.1` | Add entry to routing table |
| `ping -c 4 8.8.8.8` | Ping 4 times to IP |
| `ping -c 4 google.com` | Ping by domain (tests DNS too) |
| `traceroute 8.8.8.8` | Trace path packets take to destination |
| `nslookup hostname` | Validate hostname IP resolution |

All ip commands reset after reboot unless made permanent!

## Making Changes Permanent

| Task | Temporary | Permanent |
|---|---|---|
| Add IP | `ip addr add` | `/etc/network/interfaces` |
| Add Route | `ip route add` | `/etc/network/interfaces` |
| ip_forward | `echo 1 > /proc/sys/net/ipv4/ip_forward` | `/etc/sysctl.conf` → `net.ipv4.ip_forward=1` then `sudo sysctl -p` |
| Apply sysctl changes | - | `sudo sysctl -p` — applies /etc/sysctl.conf settings to live kernel without reboot |

## Key Files

| File | Purpose |
|---|---|
| `/proc/sys/net/ipv4/ip_forward` | Live kernel switch for packet forwarding |
| `/etc/sysctl.conf` | Permanent kernel parameter config |
| `/etc/network/interfaces` | Permanent network interface config |

## Concepts

| Term | Meaning |
|---|---|
| Switch | Connects devices within the same network |
| Router | Connects two different networks |
| Gateway | Exit door for traffic going outside your network |
| `/proc/` | Not a real folder — live window into kernel's brain |
| ip_forward | Allows VM/machine to act as router between interfaces |
| NAT | VM hidden behind host, gets internet via host |
| Loopback lo | Virtual interface, machine talking to itself 127.0.0.1 |
| MAC Address | Physical hardware ID of network card |
| TTL | Time To Live — how many hops a packet can travel |
| `* * *` in traceroute | Router is reachable but blocking ICMP, not broken |
