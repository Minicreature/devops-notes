# DNS (Domain Name System)

## Key Files

| File | Purpose |
|---|---|
| `/etc/hosts` | Local hostname to IP mapping (local truth) |
| `/etc/resolv.conf` | DNS server configuration |
| `/etc/nsswitch.conf` | Controls order of name resolution |

## Commands & Variations

| Command | Use |
|---|---|
| `cat /etc/hosts` | View local host entries |
| `cat /etc/resolv.conf` | View configured DNS servers |
| `cat /etc/nsswitch.conf` | View name resolution order |
| `cat /etc/nsswitch.conf \| grep hosts` | Check only host resolution order |
| `nslookup hostname` | Query DNS only (ignores /etc/hosts) |
| `nslookup google.com` | Query DNS for public domain |
| `dig hostname` | Detailed DNS query with full response |
| `dig google.com` | Detailed query for public domain |
| `ping -c 4 hostname` | Test full resolution chain |
| `resolvectl status` | Show upstream DNS server in use |
| `systemctl status systemd-resolved` | Check local DNS middleman service |

## Adding Entries

| Command | Use |
|---|---|
| `echo "1.1.1.1 hostname" \| sudo tee -a /etc/hosts` | Add host entry |
| `echo "nameserver 8.8.8.8" \| sudo tee -a /etc/resolv.conf` | Add DNS server |

## Record Types

| Record | Use |
|---|---|
| `A` | Hostname → IPv4 address |
| `AAAA` | Hostname → IPv6 address |
| `CNAME` | Hostname → Another hostname (alias) |

## Key Concepts

| Concept | Meaning |
|---|---|
| `127.0.0.53` | systemd-resolved (local DNS middleman on Ubuntu) |
| `10.0.2.3` | VirtualBox built-in DNS (only on VirtualBox VMs) |
| `nslookup vs ping` | nslookup skips /etc/hosts, ping uses full chain |
| `sudo tee -a` | Write to root-owned files via pipe |
| `[NOTFOUND=return]` | Stop resolution chain if mDNS says not found |

## Domain Names Structure

| Part | Example | Meaning |
|---|---|---|
| Root | `.` | Top of DNS hierarchy |
| TLD | `.com` | Commercial |
| TLD | `.net` | Network |
| TLD | `.edu` | Educational |
| TLD | `.org` | Non-profit |
| Domain | `google` | Organisation name |
| Subdomain | `www` | Service under domain |

## Resolution Order (Ubuntu VM)

    /etc/hosts (files)
          ↓
    mdns4_minimal
          ↓
    DNS Server

## DNS Chain (Ubuntu VM)

    App
     ↓
    127.0.0.53 (systemd-resolved)
     ↓
    10.0.2.3 (VirtualBox DNS)
     ↓
    Router → ISP DNS
     ↓
    Root → TLD → Authoritative
