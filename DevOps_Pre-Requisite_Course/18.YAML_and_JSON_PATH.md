# YAML & JSON PATH

## YAML

### Commands & Variations

| Command/Tool | Use |
|---|---|
| `cat file.yaml` | View YAML file contents |
| `python3 -c "import yaml; print(yaml.safe_load(open('file.yaml')))"` | Parse & validate YAML via Python |
| `python3 -c "import yaml, sys; yaml.safe_load(sys.stdin)"` | Validate YAML from stdin |

### Key Structures

| Structure | Syntax | Notes |
|---|---|---|
| Key-Value Pair | `Key: Value` | Colon must be followed by a space |
| List (Array) | `- item under a key` | Dash + space before each item |
| Dictionary (Map) | Indented key-value pairs under a key | Consistent indentation is mandatory |
| Nested Dict in List | `- Key:` then indented properties | Extra 2 spaces indent under the dash |
| Comment | `# your comment` | Ignored by parser |

### Dictionary vs List

| Feature | Dictionary (Map) | List (Array) |
|---|---|---|
| Order | Unordered | Ordered — sequence matters |
| Structure | Key-Value pairs | Sequence of elements |
| Use case | Properties of one entity | Multiple items of same type |

### Indentation Rules

| Rule | Detail |
|---|---|
| Standard indent | 2 spaces (never tabs) |
| List items | Dash at parent level, content 2 spaces in |
| Nested dict | Each level adds 2 more spaces |
| Wrong indent = wrong structure | Extra space changes parent-child relationship |

### Structure Examples

    # Simple Key-Value
    Fruit: Apple

    # List
    Fruits:
      - Apple
      - Banana

    # Dictionary
    Banana:
      Calories: 105
      Fat: 0.4 g

    # List of Dictionaries (most common in DevOps configs)
    Fruits:
      - Banana:
          Calories: 105
          Fat: 0.4 g

### Key Concepts

| Concept | Meaning |
|---|---|
| Serialization format | Converts data structures into storable/transmittable text |
| Human-readable | Designed to be easy for humans to read and write |
| Used heavily in | Kubernetes manifests, Docker Compose, Ansible, CI/CD pipelines |
| YAML vs JSON | YAML is a superset of JSON — all valid JSON is valid YAML |
| Parser sensitivity | One wrong space = broken file, especially in Kubernetes |

## JSON PATH

### Commands & Variations

| Tool/Command | Use |
|---|---|
| `python3 -c "import json; print(json.load(open('file.json')))"` | Parse & read a JSON file |
| `python3 -c "import json,sys; json.load(sys.stdin)"` | Validate JSON from stdin |
| JSONPath online tester | jsonpath.com — test queries live |
| jsontoyaml.com | Convert between JSON and YAML |

### JSONPath Query Syntax

| Query | What it does |
|---|---|
| `$` | Root element of the document |
| `$.key` | Access a key at root level |
| `$.key.subkey` | Access nested key (dot notation) |
| `$[0]` | First element of a root array |
| `$[3]` | Fourth element (0-indexed) |
| `$[0,3]` | Multiple elements by index |
| `$.car.wheels[1]` | Second item in wheels array |
| `$.car.wheels[1].model` | Specific property of that item |
| `$.car.wheels[?(@.location == "rear-right")].model` | Filter by property value |
| `$[?(@ > 40)]` | Filter array by numeric condition |

### Filter Syntax Breakdown

| Symbol | Meaning |
|---|---|
| `?()` | Filter expression |
| `@` | Current element being evaluated |
| `==` | Equal to |
| `!=` | Not equal to |
| `> < >= <=` | Numeric comparisons |

### Key Concepts

| Concept | Meaning |
|---|---|
| JSONPath | Query language for JSON — like SQL but for JSON data |
| `$` (root) | Every JSONPath query starts here |
| 0-indexed arrays | First element = [0], second = [1] |
| Query always returns array | Even single result comes back wrapped in [ ] |
| Dot notation | Navigate nested keys using . |
| Filter criterion | Use when index is unknown — filter by property value instead |

### YAML vs JSON — Quick Comparison

| Feature | YAML | JSON |
|---|---|---|
| Readability | More human-friendly | More machine-friendly |
| Syntax | Indentation-based | Braces {} and brackets [] |
| Comments | Supported (#) | Not supported |
| Used in | K8s manifests, Ansible, Docker Compose | APIs, configs, data exchange |
| Relation | YAML is a superset of JSON | JSON is valid YAML |

### Structure Examples

    // Dot notation
    $.car.color

    // Array index
    $.car.wheels[1].model

    // Filter by value
    $.car.wheels[?(@.location == "rear-right")].model

    // Filter numbers greater than 40
    $[?(@ > 40)]
